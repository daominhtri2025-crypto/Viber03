Chạy Sơn Trà Số trên macOS

Dành cho Mac Apple Silicon (M1–M4), macOS 26. Chạy hoàn toàn trên máy cá nhân: không cần tài khoản Cloudflare, không gọi Gemini, YouTube hay gửi email thật.

Thực hiện trong Terminal (Applications > Utilities > Terminal). Các lệnh chạy được với zsh, shell mặc định của macOS.

1. Chuẩn bị

Thành phần Yêu cầu Kiểm tra
Xcode Command Line Tools Có sẵn git --version
Node.js 24 (khuyến nghị); tối thiểu 22.13 node --version
pnpm 11.25.0 (đúng trường packageManager) pnpm --version
Dung lượng trống Khoảng 2 GB

Cài Command Line Tools nếu chưa có:

xcode-select --install

Cài Node.js bằng một trong hai cách:

  • Cách A: tải bản LTS (file .pkg, chọn Apple Silicon) từ https://nodejs.org, cài xong mở lại Terminal.

  • Cách B: Homebrew (https://brew.sh), rồi:

    brew install node@24
brew link --overwrite --force node@24

Cài pnpm đúng phiên bản (không dùng sudo):

npm install -g pnpm@11.25.0

Kiểm tra đủ bốn lệnh:

git --version && node --version && npm --version && pnpm --version

Kết quả: node từ v22.13.0 trở lên, pnpm là 11.25.0. Nếu node báo phiên bản cũ, đóng và mở lại Terminal.

2. Lấy mã nguồn

mkdir -p ~/Documents/du-an && cd ~/Documents/du-an
git clone https://github.com/daominhtri2025-crypto/VIBER_CODE.git viber_code
cd viber_code
git checkout Son_tra_so
  • Nhánh làm việc là Son_tra_so, không phải main.
  • Không đặt dự án trong iCloud Drive (~/Library/Mobile Documents). iCloud có thể làm hỏng node_modules và .wrangler.

3. Cài thư viện

pnpm install --frozen-lockfile

--frozen-lockfile buộc dùng đúng pnpm-lock.yaml. Nếu báo lỗi lockfile, không bỏ cờ này; báo người phụ trách.

4. Cấu hình biến môi trường

Biến môi trường cục bộ đặt trong tệp .dev.vars ở thư mục gốc dự án. Tệp này đã có trong .gitignore, không được commit.

cp .dev.vars.example .dev.vars
open -e .dev.vars

Nội dung tối thiểu:

OWNER_EMAIL=seedy@sites.test
ADMIN_PASSWORD=<mật-khẩu-của-anh-tối-thiểu-10-ký-tự>

Bảng biến:

Biến Bắt buộc Dùng để Ghi chú
OWNER_EMAIL Có Email đăng nhập quản trị Cục bộ dùng seedy@sites.test
ADMIN_PASSWORD Có Mật khẩu quản trị lần đầu Chỉ có tác dụng khi tạo tài khoản quản trị lần đầu; sau đó đổi trong ứng dụng
RESEND_API_KEY Không Gửi email quên mật khẩu Thiếu thì yêu cầu quên mật khẩu trả 503
MAIL_FROM Không Địa chỉ người gửi Phải thuộc tên miền đã xác minh trên Resend
APP_BASE_URL Không Gốc liên kết trong email Phải bắt đầu bằng https://; http://localhost bị từ chối

Kiểm tra tệp không bị commit:

git check-ignore -v .dev.vars

Phải in ra một dòng chứa .dev.vars. Nếu không in gì, dừng lại.

Quy tắc: không ghi ADMIN_PASSWORD, RESEND_API_KEY hay token vào mã, tài liệu, ảnh chụp màn hình hoặc trò chuyện.

5. Build

pnpm build
test -f dist/server/wrangler.json && echo "OK: wrangler.json"

Build tạo dist/server/wrangler.json (cấu hình D1 và R2 cục bộ) và dist/client/. Thư mục dist/ không được commit.

6. Tạo cơ sở dữ liệu cục bộ (12 migration)

Dự án có 12 migration, 0000 đến 0011. Thiếu một tệp, trang học sẽ lỗi.

for f in drizzle/*.sql; do
  echo "Áp dụng $(basename "$f")"
  node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB \
    --local --config dist/server/wrangler.json --persist-to .wrangler/state --file "$f" \
    || { echo "LỖI ở $(basename "$f")"; break; }
done

Kiểm tra số bài:

node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB \
  --local --config dist/server/wrangler.json --persist-to .wrangler/state \
  --command "SELECT COUNT(*) AS so_bai FROM lessons"

Phải có "so_bai": 10.

Tham số --persist-to .wrangler/state là bắt buộc. Máy chủ pnpm dev đọc kho tại .wrangler/state. Thiếu tham số này, migration ghi vào kho khác, và /api/lessons trả lỗi "Chưa thể tải dữ liệu" dù các lệnh đã báo thành công.

Không chạy lại migration trên kho đã có dữ liệu. Muốn làm lại từ đầu, xóa .wrangler/ sau khi người phụ trách xác nhận.

7. Chạy ứng dụng

pnpm dev

Máy chủ chạy tại http://127.0.0.1:5173 (chỉ lắng nghe trên máy này). Để giữ cửa sổ này mở; dừng bằng Control + C.

Đường dẫn Mô tả
/home.html Trang học
/admin.html Trang điều phối (cần đăng nhập)
/print.html Tài liệu in

Mở Terminal thứ hai để kiểm tra API:

curl -s http://127.0.0.1:5173/api/lessons | head -c 120; echo

Kết quả đúng: JSON có khóa "lessons" với 10 bài. Nếu thấy Chưa thể tải dữ liệu, quay lại bước 6.

8. Đăng nhập quản trị lần đầu

  1. Mở http://127.0.0.1:5173/admin.html.
  2. Email: giá trị OWNER_EMAIL trong .dev.vars.
  3. Mật khẩu: giá trị ADMIN_PASSWORD.
  4. Hệ thống yêu cầu đổi mật khẩu ngay. Đặt mật khẩu mới (10–200 ký tự) và lưu vào Trình quản lý mật khẩu của macOS.

Từ lần sau, dùng mật khẩu mới. ADMIN_PASSWORD không còn tác dụng.

9. Kiểm thử

npm test
echo "Mã thoát: $?"

Kết quả đạt: 27 dòng PASS, mã thoát 0. Kiểm thử không gọi dịch vụ bên ngoài.

Kiểm tra kiểu TypeScript:

pnpm exec tsc --noEmit

10. Cập nhật mã

cd ~/Documents/du-an/viber_code
git pull origin Son_tra_so
pnpm install --frozen-lockfile
pnpm build

Nếu có migration mới (số lớn hơn 0011), chỉ áp dụng các tệp mới, cùng lệnh ở bước 6 với tên tệp tương ứng.

11. Sự cố thường gặp

Triệu chứng Nguyên nhân Cách xử lý
node báo phiên bản cũ Terminal mở trước khi cài Đóng và mở lại Terminal
EACCES khi npm install -g Node cài bằng quyền hệ thống Cài lại bằng Homebrew (bước 1), không dùng sudo
pnpm không nhận diện Terminal cũ Mở lại Terminal
--frozen-lockfile báo lỗi Lockfile không khớp Kiểm tra nhánh Son_tra_so; báo người phụ trách
wrangler.json không tồn tại Chưa build Chạy pnpm build
/api/lessons trả 503 Migration ghi sai kho Chạy lại bước 6 có --persist-to .wrangler/state
Cổng 5173 bận Ứng dụng khác dùng cổng Chạy pnpm dev -- --port 5180 (đổi cổng)
Quên mật khẩu trả 503 Thiếu biến email hoặc APP_BASE_URL không phải https Xem bước 4
Operation not permitted Terminal chưa có quyền truy cập thư mục Cài đặt hệ thống > Quyền riêng tư và bảo mật > Files and Folders

12. Lưu ý

  • Không commit .dev.vars, .wrangler/, dist/.
  • Không dùng sudo để cài thư viện.
  • Không đổi máy chủ sang 0.0.0.0.
  • Không đặt dự án trong iCloud Drive.
